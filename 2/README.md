# Technical Incident Investigation: Home Depot GraphQL 403 Blocking

## 1. Executive Summary
A technical root-cause analysis was completed regarding a client-reported issue involving an elevated failure rate (`403 Forbidden` and silent redirects) when calling Home Depot's Federation GraphQL Gateway (`storeFulfillment` operation) via automated requests. 

By testing the endpoint over varied operational layers, we successfully reproduced the blocking mechanism and identified the precise architectural limitations of flat HTTP request replays.

## 2. Technical Findings & Failure Points

### A. Akamai Bot Manager Premier Mitigation (Primary 403 Block)
The customer attempted to replay a static session cookie value (`bm_s`) across multiple automated iterations.
* **The Mechanism:** The `bm_s` cookie is a short-lived token generated by **Akamai Bot Manager Premier**. Akamai cryptographically correlates this token with the explicit connection fingerprint of the initial browser—specifically the **TLS Handshake Profile (JA3/JA4)** and **HTTP/2 frame order**.
* **The Failure Point:** Replaying this cookie via an automated script strips away this signature link. Akamai flags the sudden profile mismatch, marks the request as a bot signature, and issues a hard `403 Forbidden` response.

### B. Contextless Direct-Link Redirects
When an automated request hits the absolute GraphQL API link directly (`://homedepot.com`) without any root browser navigation history, DOM viewport geometry, or page window memory context, Akamai perceives it as abnormal scraper entry traffic. 
* To protect the backend data streams, Akamai triggers a silent redirect loop, forcing the automated request to pull back the desktop corporate home page template instead of pure JSON data arrays.

## 3. Recommended SDK Architecture
To consistently resolve these blocking layers, the extraction pipeline must shift from raw cookie replaying to a multi-conditional browser emulation configuration inside the SDK:
1. **Initial Storefront Navigation:** Configure the SDK to navigate to the primary user product directory link (`https://homedepot.com`). This forces the headless browser instance to clear Akamai's native frontend JavaScript loops and naturally establish its own valid authentication cookies.
2. **Global State Extraction:** Once the page state resolves, instead of firing out-of-band network calls that trigger Content Security Policy (CSP) rejections, extract the live data arrays directly out of the page's global script cache variable: `window.__APOLLO_STATE__`.
